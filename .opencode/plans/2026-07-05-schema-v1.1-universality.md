# Schema v1.1: Universal Architecture Expressiveness

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Extend the architecture model schema from 7 entity types to support universal system modeling without adding new top-level entity types — via `kind` discrimination on Components, `pattern` enrichment on Behaviors, `schema` references on Interfaces, and an `extensions` envelope on all entities/relationships.

**Architecture:** Hybrid enrichment approach. Keep the 7x8 core (7 entity types, 8 relationship types) intact. Add optional fields that enable viewpoint-based filtering (logical, information, deployment, process). All changes are backward-compatible MINOR additions — existing v1.0 YAML validates against v1.1.

**Tech Stack:** Python dataclasses, JSON Schema Draft 2020-12, PyYAML, jsonschema, pytest

**Breaking change risk:** NONE. All new fields are optional with sensible defaults.

```python
def _check_v11_semantics(model: ArchitectureModel, issues: list[ValidationIssue]) -> None:
    """v1.1 semantic checks: data-model completeness, state-machine integrity."""
    from .types import ComponentKind, BehaviorPattern

    # Data-model components without fields: INFO hint
    for comp in model.entities.components:
        if hasattr(comp, 'kind') and comp.kind == ComponentKind.DATA_MODEL and not comp.fields:
            issues.append(ValidationIssue(
                severity=Severity.INFO,
                code="DATA_MODEL_NO_FIELDS",
                message="Data-model component has no fields defined",
                entity_id=comp.id,
            ))

    # State-machine: check for unreachable states
    for beh in model.entities.behaviors:
        if hasattr(beh, 'pattern') and beh.pattern == BehaviorPattern.STATE_MACHINE and beh.states:
            all_targets = set()
            for state in beh.states:
                for t in state.transitions:
                    all_targets.add(t.get("to", ""))
            # First state is implicitly the initial state
            reachable = {beh.states[0].name} | all_targets
            for state in beh.states:
                if state.name not in reachable:
                    issues.append(ValidationIssue(
                        severity=Severity.WARNING,
                        code="STATE_UNREACHABLE",
                        message=f"Orphan state '{state.name}' has no incoming transitions",
                        entity_id=beh.id,
                    ))
```
